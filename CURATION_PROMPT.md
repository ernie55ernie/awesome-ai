# Awesome AI Curation Prompt

You are maintaining a GitHub repository called `awesome-ai`.

Goal:
Build and maintain a high-quality Awesome List of Artificial Intelligence research, frameworks, and datasets, starting from GitHub repositories.

Scope:
Include resources related to:
- Large Language Models (LLMs)
- Computer Vision
- Audio & Speech Processing
- Generative Art & Video
- AI Agents & Frameworks
- MLOps & Data Engineering
- Datasets & Training Data
- Reinforcement Learning
- Machine Learning Frameworks (PyTorch, JAX, etc.)
- Ethics, Safety & Alignment
- Edge AI & Quantization

Exclude:
- Low-quality toy projects or basic tutorials
- Abandoned repos with no clear research or production value
- Repositories that are just thin wrappers over OpenAI's API
- Projects with unclear licensing
- Duplicate forks unless the fork is substantially more maintained

Quality criteria:
For each candidate repo, evaluate:
1. Relevance to advanced AI research or engineering
2. Code quality
3. Documentation quality
4. Community signal: stars, forks, issues, recent activity (must have >20 stars and active in the last year)
5. Reproducibility: examples, notebooks, datasets, papers
6. License clarity

Output format:
Generate a clean `README.md` in Awesome List style, grouped by the scope topics above. Each item should list its name, description, primary language, stars, forks, last updated time, and license.
